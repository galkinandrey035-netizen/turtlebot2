# TurtleBot

Клиентский Fabric-мод для Minecraft 1.20.1 (Java 17). Телепортируется /home, идёт к сундуку,
забирает морскую траву, кормит взрослых черепах и возвращается за травой, пока сундук не опустеет.

## Сборка .jar без IDEA (GitHub Actions)

1. Создайте репозиторий на GitHub и загрузите туда все файлы проекта с сохранением путей
   (в веб-интерфейсе: Add file → Create new file, в имени указывайте путь целиком).
2. Откройте вкладку Actions → workflow build (запускается при каждом push).
3. Дождитесь зелёной галочки и скачайте артефакт TurtleBot. Внутри turtlebot-1.0.0.jar.
4. Для релиза создайте тег v1.0.0: jar появится в разделе Releases.

## Локальная сборка

Нужны JDK 17 и Gradle 8.5:
```bash
gradle build
```
Готовый jar: `build/libs/turtlebot-1.0.0.jar` (файл `-sources.jar` не нужен).

## Установка

Fabric Loader ≥ 0.15 и Fabric API для 1.20.1. Положите jar в `mods/`.
Необязательно: Mod Menu + Cloth Config (экран настроек на русском).

## Команды (/turtlebot или /tb)

| Команда | Действие |
|---|---|
| `start` / `stop` | запуск / остановка |
| `pause` / `resume` | пауза / продолжить |
| `status` | состояние, трава, база черепах |
| `reload` | перечитать конфиг и базу |
| `clear` | очистить базу черепах |
| `chest set` | задать сундук по прицелу (или `chest set x y z`) |
| `chest show` | показать сундук |
| `radius [n]` | радиус поиска (4–64) |

## Быстрый старт

1. Встаньте рядом с сундуком с травой, наведите прицел и выполните `/tb chest set`.
2. Убедитесь, что `/home` приводит к сундуку (и к черепахам рядом).
3. Выполните `/tb start`.

## Файлы данных

- `config/turtlebot/config.json` — настройки.
- `config/turtlebot/turtles.json` — база черепах (UUID, таймеры кормления).

## Как это работает

- Конечный автомат: телепорт → ожидание → путь к сундуку → открыть → взять траву → закрыть →
  поиск черепах → подход → кормление → возврат за травой / ожидание перезарядки → конец.
- Кормление подтверждается уменьшением стака травы в руке.
- Детёныши (`isBaby`) не кормятся: проверка при поиске, подходе и перед взаимодействием.
- Яйца: клетка с яйцом и зона `eggMargin` вокруг запрещены для A*. Бот не прыгает и не использует атаку;
  начало разрушения блоков блокируется через `AttackBlockCallback`.
- Навигация: собственный A*, 8 направлений, спуск до `maxDrop`, без подъёмов, прыжков и жидкостей.

## Известные ограничения

- Проект ещё не был успешно скомпилирован и протестирован. Первая сборка может выявить несовместимость
  Yarn API или зависимостей Mod Menu / Cloth Config. Если GitHub Actions завершится ошибкой, нужен лог.
- Только ровная местность: бот не поднимается на ступеньки, полублоки и склоны.
- Черепахи в воде недоступны, поскольку навигация обходит жидкости.
- В творческом режиме трава не расходуется, поэтому подтверждение кормления может не сработать.
- Таймеры используют реальное время.
- Блокировка ломания неполная: перехватывается только начало разрушения.
- Если `/home` требует подтверждения или долго выполняется, увеличьте `teleportTimeoutSeconds`.
- Проверьте правила сервера: автоматизация может быть запрещена. Первый запуск лучше сделать в одиночной игре.
